## 展示内容与顺序

1. 用一句话说明真实问题：路线可行不代表箱体装得下、按顺序卸得出；异常后的重排必须尊重原摆放与执行事实。
2. 单击首页“开始完整演示”，看六店十二箱的联合方案、实际计算坐标、逐店卸货，再看十八条模拟回执与回仓。
3. 三个构造反例现场重新求解：尺寸改变选车；改序受原摆放限制；易碎堆叠保留未安排订单。
4. 交互模式核对改窗字段、生成候选、再核对采用；单独确认到达、卸货、签收。可在专业工作台查看保存历史与交接。
5. 展示独立核验和失败边界：不完整候选禁止采用，已签收事实不被撤回；费用上升、无改善和搜索失败都保留。
