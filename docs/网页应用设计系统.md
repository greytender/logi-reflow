# 城配续航网页应用设计系统

2026-10-12。依据UI UX Pro Max的设计系统检索与UX检索执行。技术栈为原生HTML/CSS/JS，保留Python标准库服务与SQLite，不引入构建框架。

检索方向包括克制留白、高对比文字、统一图标、语义颜色、渐进呈现、清晰导航、键盘焦点、44px操作目标及减少动画。面向中文物流评审与调度，采用墨绿与暖白，而非检索模板中的粉色和时尚衬线字体。没有新增在线字体或CDN依赖。

变量集中在web/app.css：正文#182f25，辅助文字#58665f，主要操作#245440，背景#f6f7f2，边界#dee5dd。字体为Segoe UI、Microsoft YaHei UI与系统回退。统一矢量图标；卡片圆角12–16px；按钮区分主次、禁用、焦点与忙碌状态。

首页一个主要行动，三个证据案例解释算法。主导航四项，完整回放三段，交互四步。AI、导入、场景管理、原始坐标与手动执行收进对应操作。不自动调用AI、采用或把预测转成签收。

旧URL只作跳转；workspace.html与cargo.html是应用内专业模块，不另保留旧/新版产品。临时交互与专业模块保存场景的状态边界明确标注。

主视觉标为算法关系示意；证据、回放和交互的箱体图使用实际求解坐标。不展示未经核验的收益比例或虚构交通地图。
