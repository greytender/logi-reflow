# 城配续航：评委演示说明

唯一入口：http://127.0.0.1:8766/ 。双击项目内“打开城配续航.cmd”可启动服务并用Chrome打开。无需配置AI就能看完算法演示。旧链接自动进入同一应用。

## 推荐展示顺序（约三分钟）

1. 首页说明：“路线能送到，箱子也得装得下、卸得出；异常后原货与执行事实不能被重算抹掉。”
2. 点击“开始完整演示”。六家门店、十二箱的构造输入现场联合计算。查看选车、访问顺序、箱体坐标与装卸步骤；拖动卸货预览，其他门店箱体保持原位。
3. 点击“查看配送回执”：六店、十八条脚本模拟回执分别记录到达、开始卸货与签收，最终回仓。不是现场业务或AI调用。
4. 点击“查看异常与交接”：查看收货变化产生的候选与代价，候选不会自动采用。
5. 回到“能力演示”，点选三个反例中的一个；数据可导出，检查依据来自同一次服务端计算。

## 三个算法能力怎样举证

| 能力 | 页面证据 | 正确解释 |
|---|---|---|
| 路线与空间联合核验 | 几何反例：小车48元不可执行，改大车117元通过核验 | 增加费用是可执行性的代价 |
| 异常后检查原坐标 | A→C→B不能按原摆放卸货；A→B→C保留45分钟迟到 | 拒绝不可执行的更快方案，不是收益证明 |
| 执行状态可追溯 | 交互保留货物归属、采用版本和三步回执 | 已签收事实不被撤回；签收后才移除箱体 |

## 现场交互

进入“交互模拟 → 自己试一次”。默认固定装载模式，点击“开始交互模拟”。查看计划，再进入“处理异常”，点击“填入收货变化示例”，核对字段并勾选，生成候选。完整候选仍需单独勾选才能采用。

“模拟执行”显示当前车辆下一任务与建议时间。勾选人工模拟确认后，每次点击只执行当前一步；到达、卸货、签收分别确认。预测时间不是现场事实。手动时钟和回执选择在可展开操作内。

普通CSV模式保留最多两个仓库紧急单，未核验3D；固定装载模式拒绝新货插入。出发后不能切换模式绕过约束。临时场景闲置两小时或服务重启失效，页面刷新需重新开始，可先导出。持久化场景、历史、导入与故障独立试算在“专业工作台”，与临时场景分开。

## AI与边界

“连接设置”可配置DeepSeek临时密钥，提交清空输入，服务端仅内存保存一小时，重启失效。设置不会自动调用模型；主动理解业务消息才会调用。无密钥可手工操作。本轮没有新增真实模型调用。

AI负责字段提取和补问，本地算法负责有限搜索与约束核验，人负责采用。没有全局最优保证，没有成熟求解器或公开标准算例对照；固定空间中新货插入、连续故障、轴荷、共同支撑、侧门、现场可达性、温控、真实业务接口与企业收益仍待实现或验证。

不要把费用增加、部分方案或构造数据中的差值说成企业降本；不要把已实现的约束组合直接宣布为原创算法。
