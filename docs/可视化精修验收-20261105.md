# 地图、路线和装卸精修

对照《城配业务场景说明》全部8页，保留原有网站配色和圆体。本轮由地图、车厢、算法执行三个子任务并行修改，主流程接入温度表单、Agent风险与版本锁定，并统一验收。逐条约束见[场景复核](场景约束复核-20261105.md)。

## 打开与演示

双击根目录“打开城配续航.cmd”，在配送工作台建立“冷链与回收示例”，保存并计算。

- **路线总览**：城区道路、建筑、仓库和门店。切换俯视或三维；展开地图，查看深色路线、方向箭头和虚线返仓。门店编号固定，另外标注第几站。下方路线清单与地图、车辆选择、装卸入口相连。
- **三维装卸**：默认看货物，整车外壳不挡住箱体。可切换看整车、俯视、尾门与侧面；按门店跳转，再逐步播放卸货、临时倒货、共享箱开箱取货与回收。侧边清单可以点选货物，单独近看。
- **执行与回收**：确认方案后，按冷链箱记录装车、在途、卸货温度。超出温区的读数可以保存，提示待处理；处置作为追加记录关联原异常。后续正常读数不会改掉此前异常。

助手默认收起，给地图和货物留出足够空间，需要时从右上角打开。页面用“门店1、车辆1、仓库1”区分对象，内部编号与记录关联保留。

## 清晰度与准确性

城区模型在没有地理坐标时使用固定道路布局，集中标“城区场景示意”；展示道路不会改写运费里程。路线严格使用候选中的门店顺序并连回仓库。提供清单作为三维不可用时的入口。地图展开在页面内完成，可收起或按Esc退出，不依赖浏览器全屏权限。

货物尺寸、坐标和前后状态来自算法，不为视觉效果填满车厢。近景通过改变镜头取景范围实现。减少重叠标签，当前操作箱体高亮，展示本步卸下、装入和冷链箱内剩余货重。箱盖可以打开，但箱壳仍留在车上。回收物和临时移出箱分别呈现。

温度记录保存来源与环节，可追加处置，也能在回仓后补录历史读数；不改变配送位置、已签收进度和保温设备启用时刻。有记录后原输入锁定，导出交接包保留原始读数与处置。Agent可以指出尚未处置的温度异常。记录只是离散观测，不等于连续测温或自动质量放行。

## 算法修复

1. 普通货、空包装与常温退货不得进入声明的冷链专用区，构造与独立审计同时检查。
2. 退货逐件收货工时计入硬时间窗和返仓时间。
3. 同等时效与费用下，优先减少冷链和易碎货搬倒，再比较总搬倒次数。
4. 开箱扣重前保存原快照，使动画和动作审计中的前后货重一致。
5. 启用能量约束时，每公里能耗不能为零。
