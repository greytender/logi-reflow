# 城配续航：完整网页功能演示视频

最终视频及分章播放入口放在 README 顶部。视频从业务问题开始，展示路线与装载联合核对、固定坐标约束、执行回执和专业工作台，并交代方法、证据和未完成能力。

所有画面来自 Tabbit 的实际网页操作，通过浏览器标签页的视频流连续录制，没有使用截图拼接。初始前台取景被用户要求停止；正式完整演示改为后台标签页录制，不再激活桌面窗口。浏览器栏、标签栏和其他应用不属于捕获范围。源页面保持桌面布局，纵向内容通过滚动展示；最终视频按原比例缩放，字幕使用独立下方空间。

旁白为本地 Microsoft Huihui 中文合成语音，配画面字幕，同时提供 SRT 和 WebVTT 文件。章节衔接和实际录像中的静止画面停留按解说长度编辑；不是未经剪辑的系统录屏。鼠标操作指示来自网页中实际点击位置，随操作移动。

演示使用端口 18778 的隔离 QA 服务和 `outputs/video-qa` 数据库。没有修改原运行数据库，也没有输入个人 AI 密钥、录制麦克风、调用付费模型或实际派单。

## 演示覆盖

1. 三个构造反例：几何不可行、原摆放卸货顺序受阻、易碎/堆叠导致未安排。
2. 六店十二箱的联合方案、五份输入说明、装车与卸货步骤预览。
3. 十八条脚本模拟回执，以及异常方案和交接信息。
4. 固定坐标交互场景：拒绝新货插入，核对事件，生成候选，再独立核对采用。
5. 手工模拟的到达、开始卸货、完成签收，直至六单十八条回执和回仓。
6. 普通 CSV 模式的两批仓库急单：采用后货物仍在仓库，取货任务分批计算；此模式没有 3D 保证。
7. 单次故障独立试算、专业 CSV 导入、保存场景与只读历史。
8. 联合装载专业核验与核对后创建固定坐标保存场景。
9. 可选 AI 设置、方法与边界、完整故事阅读入口。

## 看懂结果时的边界

48 元方案在构造几何反例中不可执行，117 元是满足约束的模拟代价；两者差值不能写成真实降本。原摆放改序反例保留 45 分钟预测迟到，两份方案均为 38 元。未安排订单也保留显示。

算法是有限启发式搜索和独立装载核验，不保证全局最优，也不是已经实现的 ALNS 或强化学习。AI 只用于可选事件字段提取与补问，候选由本地算法核验、人工核对采用。固定装载新货插入、连续故障、温控、轴荷、真实业务接口及企业收益仍未实现或验证。

视频断言与媒体检查记录见 `evidence/video-verification-20261012.json`。既有 185 项测试和此前 13 组 Chrome 检查保留原日期；本轮 Tabbit 录像验证另行记录。

## 制作文件

`docs/video-narration.json` 是旁白正文；`scripts/prepare_video_narration.ps1` 生成本地语音。`scripts/tab_recording_control.html`、`scripts/recording_sink.py`、`scripts/record_background_walkthrough.py` 和 `scripts/capture_walkthrough.js` 用于隔离环境里的后台标签页录制；`render_background_walkthrough.py` 生成视频、字幕与章节。

普通应用仍只依赖 Python 标准库。制作视频另需本地中文语音和 FFmpeg；此处使用安装在忽略目录 `outputs/media-tools` 中的 imageio-ffmpeg。原始录像、临时语音、字体副本、共享标识、临时保存令牌、数据库及制作日志均不进入仓库。
