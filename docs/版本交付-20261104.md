# 城配续航 · 2026-11-04 交付记录

## 算法

在四地公开空间输入上构造32种约束组合、每地两波次，共256批、1024次搜索。训练、筛选和最终情景分开，逐候选用独立算术回放核对；所有候选锁定原在用车队，逐车重量/体积利用率降幅不超过2个百分点，名义全覆盖、准时且运费不增。

最终8192组情景中，规则基线通过4004组；名义局部修复3924组，情景局部修复4008组，情景ALNS的两种子中位数3974组。独立筛选通过4020组，替换26批，其中16批改善、10批退化。结果不足以建立跨场景自动选算法规则，生产默认保持原流程。

回收试算现要求当前完整方案作为比较基线，复用固定车队、装载降幅和名义运费护栏。工作台的小规模试算只报告求解情景内表现，不保存或自动采用配送候选。

## 页面

首页、能力页、场景页、指南与工作台共用中文圆体和浅玉、雾蓝、暖杏配色。首页精简文字；工作台与调度对话增加字号和留白，采用玻璃圆角面板与按压反馈。动画支持系统“减少动态效果”设置。

保留模拟数据、待核验、原计划/剩余预测和未接入企业系统的必要标识。方案确认、规则应用、签收与返仓仍有独立人工操作。

字体自托管，保留上游完整字符映射和SIL OFL授权，不上传系统字体。具体版本、处理方式与复现命令见 [字体说明](../web/fonts/README.md)。

## 验证

全量349项自动测试通过，耗时50.530秒。另复算8仓96任务、32辆可用车的构造边界批次，计算、独立核验和本地确认通过。原始Excel的SHA-256与先前完整核对记录一致，原文件未修改。

从Git暂存区提取的干净副本也完成349项测试，耗时48.633秒，确认不依赖未提交的本机文件。干净副本首次运行曾有一次Windows本机连接中断（WinError 10053）；未修改实现，相关10项专项及随后全量复跑均通过。原始日志保留在本机 `outputs/`，这不等于已证明所有平台均无偶发连接问题。

后台Chrome在1440px桌面和390px手机上完成两轮有界检查，记录七种画面。圆体实际加载；检查画面可见文字均不小于14px，无页面横向溢出和JavaScript错误。实测模拟任务创建、计算、选车、未发送草稿保留、显式勾选确认、模拟签收、事实锁、刷新恢复及手机助手开关。额外用真实本地风险工具输出验证对话区域，不调用付费模型。

常规模式下路线动画存在，系统减少动态效果时动画停用。独立视觉审查实际查看首页、工作台和手机助手六张截图后给出 `ship`，无实质修复项；独立核心审查另运行24项针对测试，逐批重建256批输入/情景指纹并复算汇总，均一致。

设计检测器因缺少HTML/CSS解析依赖而降级为正则扫描，其旧设计尺度告警由本轮设计文档更新；描边宽度过渡被机械识别为布局宽度过渡，不是完整布局或对比度认证。未实测手机软键盘、屏幕阅读器及所有透明叠层的对比度。

## 验证边界

所有算法实验及本轮网页操作均为构造模拟任务。公开点位/匿名距离矩阵不是传化公路港运营数据；真实道路、费率、回收回执、同批人工计划和企业收益未验证。回收物仍按重量/总体积核验，不能当作回收物三维摆放或冷链验证。

本轮不新增真实付费模型调用。浏览器工具的本机服务路径已修正并备份，但当前进程仍引用旧路径，需重启应用后验证插件连接；页面使用独立后台Chrome检查，不控制用户窗口。
