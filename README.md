# 城配续航

从一张订单表，到一趟能核对、能调整的配送方案。

## 下载并打开

**[下载最新城配续航.zip](https://github.com/greytender/logi-reflow/raw/refs/heads/main/城配续航.zip)**

1. 下载并完整解压 `城配续航.zip`，不要在压缩包里直接运行。
2. 双击解压文件夹里的 `打开城配续航.cmd`，浏览器会自动打开本地网站。
3. 演示期间保持启动窗口开启；结束后按 `Ctrl+C` 停止服务。

适用 Windows 10/11、Intel/AMD 64 位电脑。包内已经带齐 Python、中文字体、三维库和演示数据，无需另装运行环境。建议使用 Edge 或 Chrome。

也可以点击仓库的 **Code → Download ZIP**。解压下载文件后，里面只有最新的 `城配续航.zip`；再将它完整解压即可使用。

如果浏览器没有自动打开，双击 `备用启动.cmd`，将窗口显示的本地地址复制到浏览器。备用窗口在程序退出或报错后仍会保留。

## 可以演示什么

内置 116 笔订单、103 家门店和 16 趟配送方案。进入工作台后，可以核对原始订单、查看配车与线路、比较方案、播放三维装卸和配送过程、试算空箱回收、导出配送清单，以及登记执行和温度记录。

页面、排车和三维展示在本地运行，离线可用。小航的大模型问答需要网络及自己的 API Key，可连接 DeepSeek、Qwen、GLM 和 Kimi。

前端使用 HTML、CSS、JavaScript、SVG 和 Three.js；后端及求解使用 Python，SQLite 保存订单、方案和执行记录。演示结果按包内车辆、道路、箱规和时间配置计算。
