工作台使用指南

支持完整业务任务与独立模拟批次。方案确认、执行记录和规则应用都有独立操作。

准备业务资料生成与核对方案与 AI 协作执行与交接

导入订单与规则

原始 Excel 进入“资料核对”页，保留原文件、原行、字段来源和单位。缺少仓库、车辆、道路或业务规则时，保留待补项，不把空值当作零。

字段完整的多仓 JSON 可以直接导入工作台。任务和车辆必须有明确仓库归属，附上可用道路、服务时间、预计回收和计费规则。工作台支持下载模拟模板。

打开原始资料核对 →

核对与确认方案

保存输入并生成排车候选。检查未安排任务、逐车顺序、费用与容量。你可以手动调整同仓车辆和顺序，重新核验后生成新候选。

只有完整通过并由你明确确认的方案，才能进入执行记录。输入或业务规则改变后，旧方案保留历史，不能冒充当前结果。

使用调度助手

在工作台的 DeepSeek 设置中填写临时密钥，或使用本机加密配置。临时密钥不进入浏览器持久存储、任务数据库或导出。设置本身不调用模型；主动发送请求时使用 API 并产生费用。

你可以说“帮我排一下这批任务”“解释这辆车的费用”“检查回收之后还有没有超容风险”。选中的批次、车辆或门店作为明确上下文，助手调用本地业务工具，展示过程和可审阅结果。

发送范围

对话会发送至 DeepSeek，包含你的消息、必要的任务上下文与工具结果。工作台显示实际状态。真实企业资料接入模型前，仍需确认数据使用范围。

记录执行与回收

逐车填写下一站完成时间、实际包装回收数量与信息来源，最后记录返仓交接。预测不会自动变成签收，已记录事实不会因重排而撤销。

位置与等待只支持已知道路节点。出现风险时，可计算同车剩余顺序候选并人工采用；导出时原计划、实际记录与剩余预测分开保存。
