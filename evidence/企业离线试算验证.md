# 企业数据离线试算入口：本轮验证

2026-10-11。用户指出原12店讲解案例无法支持企业迁移，本轮增加可导入数据的出发前离线入口。旧0.8服务、连续场景和密钥不改，未新增付费AI调用、外部推送、邀请或比赛提交。

## 已实际执行

- `python -m unittest discover -s tests -v`：77项通过，最终8.166秒；原68项与新增9项，子情境不额外计数。包括SKU汇总、缺路拒绝、同店规则冲突、硬截止与回仓班次、车辆准入、复核识别伪造时间/费用，以及不满足三角不等式的道路捷径。
- `python reproduce_demo.py`：原P1→P2→P3在临时数据库复现，独立核验通过；原迟到51.32→15.66分钟、模拟费用219.48→226.16不变。
- `python pilot.py examples/pilot-30 --output outputs/pilot-30`：实际导入30个门店、300行SKU、5辆车、930条有向道路记录；输出两方案、独立复核、逐站CSV和未安排CSV。
- `python pilot_benchmark.py`：8个构造场景，两方案各通过独立算术复核；缺道路、重复SKU、未知车辆3种坏输入全部拒绝。原始结果见 `pilot-benchmark.json`，生成器和种子保留。

## 修复与限制

道路表下删去一个节点可能使捷径更慢，旧移位算法曾对不可行的删除路线取值；已增加可行性判断并用专门回归情境验证。新入口不补猜缺失道路，不使用真实地图API或实时路况。

本轮提供可执行的数据合同和导入/导出工具，并不等于企业上线。连续异常仍未使用新数据合同；多SKU只检查总重量体积，不能表示3D装载、易碎堆叠或冷链可行。司机签收、企业接口、真实企业排程对照和生产可靠性未验证。行业原始数据全部缺失，当前样本及道路表均自制模拟。

README新增入口链接；原连续网页依然标0.8，不把离线扩展冒充连续能力升级。当前改动留在本地，待后续形成完整检查点再按用户既有同步节奏处理。
